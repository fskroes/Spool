    The idea

    Scroll the view. Keep the size.

    A tiling manager cuts the screen into pieces. Open one more window and every piece gets smaller. Spool does not cut. It lays windows on a strip that is wider than the display.

    Grid

    The screen is shared. Each new window takes a part.

    Strip

    Each window keeps its width. The view moves.

    No shrinking

    Opening a window never makes the other windows smaller. The strip gets longer. Your windows keep their width.

    One strip each

    Every display and every Space has its own strip. The strips come back after you restart the app.

    Move the view

    Use a key, a trackpad swipe or a CLI command. Springs move the view. A new key press changes the target of the move in progress, so the view never stops and starts again.

    Automation

    A CLI that agents and scripts can read.

    The spool tool sends one request to the running app. It prints nothing when a command works. Add --json to get the full state for a script.

    spool focus-right
spool state
spool state --json | jq -r '.state.displays[].columns[][].bundleID'
spool stats
# the same commands as a URL
open -g spool://focus-right
open spool://settings/shortcuts

    Example output of spool state, from docs/CLI.md

    Engine: running. Accessibility: granted.

    * marks the focused column. + joins the windows of a stacked column. spool stats shows live frame write times, Spool's own part of them, command latency and the slowest apps. Raycast: the folder Integrations/Raycast has Script Commands for the main commands and a "Spool State" command. The jq line needs jq (brew install jq). More: spool --help.

    Speed

    Measured, with the budget next to it.

    Numbers from make bench on 2026-10-13. Apple silicon, macOS 26, load average 4.8. Your Mac will differ, so run the bench yourself.

    Bar length is the measured time as a share of the budget from docs/SPEC.md.
    MetricBudgetMeasuredShare of budget
    Layout and placement of 50 columns, per frame< 50 µs6.3 µs
    Frame write, 6 apps with 2 ms AX latency each, p95 of 100 rounds< 4 ms3.18 ms
    Spool's part of that frame write, p95< 1 ms0.12 ms

    Writing the same six frames one after the other takes 18.1 ms. Spool writes to each app on its own queue and keeps only the newest frame for a busy app. When all windows are at rest there is no timer and no display link. The rest of a frame write is the time apps and WindowServer need to answer the AX calls. Spool cannot make that shorter.

    Features

    What is in the box.

    • Endless horizontal strip per display and per Space
    • Spring animations that follow a new key press at once
    • Minimap of the strip when the view moves
    • Stacks and tabbed columns
    • Preset widths, full width, wider and narrower
    • Center the focused column: never, on overflow, always
    • Trackpad swipe with 3 or 4 fingers, with fling and snap
    • Drag a window to a new place; resize from an edge sets the width
    • Multi-monitor, one strip each
    • Per-app rules: tile, float, fixed place
    • Focus border and dimming of other windows
    • Launch at login; the strips come back after a restart
    • Every shortcut can be changed
    • Local metrics and spool report

    Honest status

    What you should know first.

    What does it cost?

    EUR 0.99, one time, VAT included. Buy it on 1yc.dev. The key works for every later version. Spool checks the key on your Mac, with no network connection. Spool.dmg is signed with a Developer ID and notarized by Apple, so macOS opens it after a download. Spool updates itself.

    What does Spool send out?

    Spool measures its own speed, cost and problems on your Mac. The metrics never leave your Mac. They keep no window titles and no keys. You can turn the metrics off in Settings > General. The only network use is the Sparkle update check: it reads the update feed of the releases on github.com.

    Is it open source?

    No. Spool is a paid app and the source is private. The license key is for your own Macs.

    Are there known limits?

    Window focus uses private SkyLight calls, as other window managers on macOS do. Trackpad swipes use the private MultitouchSupport framework. A future macOS can change them. Spool then falls back to normal app activation for focus.

    Can I use it on a work Mac?

    If your employer manages the Mac, ask IT first. See the install guide, section "Use on a managed work Mac".

    Was it called Striple?

    Yes. Spool had the name Striple before. make install replaces Striple, and Spool moves your settings at its first start. See the install guide, section "Upgrade from Striple".

    Is it a copy of another app?

    No. Spool is a clean-room app. It follows the public descriptions of niri and PaperWM and the public feature pages of similar macOS apps. No third-party binary was decompiled.
